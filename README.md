# 怪異探偵部 PART BREAK

東京鬼高校・怪異探偵部の三人——改造人間のJK、吸血鬼のニート、狼人のメイド——的手繪點陣格鬥遊戲，
主打「部位破壞」：每個角色有四個可破壞的部位，打壞了外觀會變、招式與能力也會變。

- **改造人間（JK）170cm** — 義手・義足・刀・制服。義手壞了重拳變肩撞；義足壞了變慢；刀斷了變短。
- **吸血鬼（ニート）152cm** — 眼鏡・筆電・拖鞋・呆毛。筆電碎了就改用牙齒和爪子，速度變快。必殺技把使い魔（蝙蝠貓）射出去。
- **狼人（メイド）165cm** — 頭飾・圍裙・封印・皮鞋。封印緞帶被打斷就會狼化：體型變大、攻擊變重、回一點血。

## 玩

直接開 `index.html`（或 `dist/index.html` 單檔版）就能玩；本機預覽：

```bash
node server.js 5200
```

| 1P | 2P | 說明 |
| --- | --- | --- |
| ← → | A D | 移動；按住後退＝防禦；連按兩下前＝衝刺、後＝後跳 |
| ↑ | W | 跳躍（空中按攻擊＝空中技） |
| ↓ | S | 蹲下；蹲下攻擊＝下段（要蹲防） |
| Z / X | J / K | 小攻擊／大攻擊，命中後連按接連段 |
| C | L | 必殺技（連段中可取消） |
| Enter | | 開始／決定；P 暫停；M 音效 |

被打中的部位（頭／身／腳）決定哪個零件受損；武器（刀、筆電）只在持有者攻擊時被打才會受損。
每破壞一個部位額外扣 4 點 HP。兩勝制、每回合 60 秒。

## 動作表流程（Gemini 生成 → 遊戲影格）

1. 用 Gemini 生成一張「同一角色、多個攻擊姿勢、帶特效、單色背景」的點陣動作表（例：ref/jk_actions.jpg）。
2. `python ref/frames.py ref/xxx_actions.jpg <角色> 4` — 以 4px 像素格重採樣、依連通區塊切成一格一格、找出腳底錨點、把「效果」與「人物」分開（效果範圍 = 判定框），輸出 `src/frames-<角色>.js` 與檢查圖 `ref/<角色>_act_cells.png`。
3. 在 `src/<角色>-frames-anims.js` 把格子編號指定給招式（`act(i)` 帶效果、`fig(i)` 只有人物），判定框直接用 `eff(i)`。
4. 站姿全身圖（ref/cast.jpg）另用 `python ref/extract.py` 切成 HUD／選角用的頭像與骨架版身體。

目前改造 JK 全部影格來自動作表；吸血鬼與女僕還沒有動作表，先用縮小的骨架版佔位。

## 做法

畫面 480×270、角色約 96～110px（KOF 尺寸）：頭、手、腳是手打點陣；上身用「材質圖」由骨架自動上明暗與接縫；四肢是圓柱明暗的筆畫；長髮是帶髮縷的飄帶。


全部點陣都是程式畫的（沒有圖片檔）：

- `src/px.js` — 1x 光柵器：材質色階、部件分離邊、外框、翻轉／旋轉。
- `src/rig.js` — 共用骨架：手繪點陣部件（頭、上身、裙、鞋）＋ IK 擺放的四肢筆畫、上身傾斜、長髮飄帶、受擊框。
- `src/jk.js` `src/vamp.js` `src/maid.js` — 三位角色（女僕含狼化型態）的點陣與破損變化。
- `src/anims.js` — 所有動作逐格定義：預備→殘影→命中→追隨→收回，含判定框與傷害。
- `src/fx.js` — 揮擊殘影、命中火花、塵土、電光等效果。
- `src/stage.js` — 480×180 的夜晚校門舞台（視差捲動）。
- `src/game.js` — 60Hz 固定步進：輸入、物理、判定、部位傷害、投射物、CPU、回合流程與 HUD。

檢視工具：`node tools/sheet.js out.png 8 jk poses.js`（姿勢表）、`node tools/anim.js out.png jk light heavy 5`（動作分格，紅框＝判定框）、`node tools/build.js`（打包成 `dist/index.html`）。
