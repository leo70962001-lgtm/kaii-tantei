# 怪異探偵部 PART BREAK

東京鬼高校・怪異探偵部の三人——改造人間のJK、吸血鬼のニート、狼人のメイド——的手繪點陣格鬥遊戲，
主打「部位破壞」：每個角色有四個可破壞的部位，打壞了外觀會變、招式與能力也會變。

- **改造人間（JK）170cm** — 義手・義足・刀・制服。義手壞了重拳變肩撞；義足壞了變慢；刀會被打飛（旋轉飛出、插在地上），走到旁邊按 ↓ 撿回來（耐久回一半）。
- **吸血鬼（ニート）152cm** — 眼鏡・筆電・拖鞋・呆毛。筆電碎了就改用牙齒和爪子，速度變快。必殺技把使い魔（蝙蝠貓）射出去。
- **狼人（メイド）165cm** — 頭飾・圍裙・封印・皮鞋。封印緞帶被打斷就會狼化：體型變大、攻擊變重、回一點血。

## 玩

直接開 `index.html`（或 `dist/index.html` 單檔版）就能玩；本機預覽：

```bash
node server.js 5200
```

| 1P | 2P | 說明 |
| --- | --- | --- |
| ← → | A D | 移動；按住後退＝防禦；連按兩下前＝衝刺、後＝後跳 |
| ↑ | W | 跳躍（空中按攻擊＝空中技） |
| ↓ | S | 蹲下；蹲下攻擊＝下段（要蹲防） |
| Z / X | J / K | Z 義手連段（炎ジャブ→ストレート→義足ミドル→横薙ぎ→ハイキック）／X 刀連段（袈裟斬→刺突→回天斬），兩條可互接 |
| ↓Z / ↓X | ↓J / ↓K | 屈み義手（再按 ↓Z＝炎の足払い，下段擊倒）／足払い（下段） |
| 空中 Z / ↓Z / X | 空中 J / ↓J / K | 空中義手／空中義足（急降下蹴り，上段）／空中斬 |
| →+X（貼身） | →+K | 投げ（不可防禦） |
| C / ↓C | L / ↓L | 影分身・居合／電磁衝撃破（光彈），連段中可取消 |
| V（氣槽滿時） | I | 超必殺「量子爆裂」：彩虹氣場蓄力後爆炸，範圍大、擊飛。氣槽（血條下的細條）打中對手 +9、被打 +5 |
| ↓（刀掉了時） | ↓ | 撿刀 |
| G / B | — | 切換 WebGL 畫面層／骨骼紙娃娃 |
| Enter | | 開始／決定；P 暫停；M 音效 |

被打中的部位（頭／身／腳）決定哪個零件受損；武器（刀、筆電）只在持有者攻擊時被打才會受損。
每破壞一個部位額外扣 4 點 HP。兩勝制、每回合 60 秒。

## 目前狀態：先只做 JK

- 舞台 480×270、JK 約 110px：待機就是站姿圖本身，其他動作的頭髮、臉、制服、裙子也是站姿圖的原始像素，四肢由骨架驅動。站姿圖用黑底單人版（ref/jk_solo.jpg，`ref/extract_solo.py` 切圖：飄髮、刀柄、刀尖完整），`src/cast.js` 組裝。
- 攻擊的斬擊效果來自 Gemini 動作表（ref/jk_actions.jpg）：`ref/frames.py` 依 4px 像素格切格、把青色效果與人物分開，`ref/clean.py` 去雜點並統一調色盤，`src/sheetfx.js` 把效果 Scale3x 放大三倍疊在對應招式上，判定框就是效果的範圍（`hbAbs`）。
- 招式姿勢照兩張 Gemini 動作表（ref/jk_actions2.jpg：突き／義足踢／蹲攻／連段／居合／義手砲，ref/jk_actions3.jpg：待機移動／連段／跳攻／特殊技・投げ／受擊倒地／勝敗）：`ref/frames2.py` 去掉標題色帶後切格（src/frames-jk2.js、frames-jk3.js），表上的青色能量效果（義手砲的光暈、光彈）直接疊用。Z 義手連段四段、X 刀連段三段、蹲攻兩種、空中兩種、投げ、居合、義手砲光彈（投射物）。
- **three.js 畫面層**（`src/gl.js`，three r170 放在 `vendor/three/`，index.html 用 importmap 載入）：遊戲每格先產生一份繪製清單（角色圖、剪影影子、殘影、粒子），2D 畫布與 WebGL 共用。WebGL 版把清單畫成透視場景裡的貼圖面片：角色所在平面 1:1 對到 480×270 的低解析度 render target（像素不糊），遠景層放在真實深度由相機產生視差，KO 時相機推進，路面有淡倒影，能量特效／月亮／路燈走第二個 bloom pass（three.js 的 selective bloom 作法，用 camera layers）。按 G 切回 2D 畫布，`?gl=0` 一開始就關。
- **骨骼綁定紙娃娃**（`src/puppet.js`、`src/jk-parts.js`）：全部以黑底站姿圖為準。`ref/parts_jk6.py` 直接用站姿圖的原像素切件（頭＋閉眼／張嘴兩種臉、前髮、後髮上下兩段、上身、裙、大腿×2、小腿×2、義手上臂／前臂／拳頭、鞋；另一袖用近側袖子鏡射、刀以站姿圖刀身／刀柄的顏色重繪），`ref/parts_x2.py` 再把所有零件 Scale2x（res 2，畫面 2 倍取樣，尺寸不變）。骨架的休息姿勢直接量自站姿圖（腰 20,50、手腕 14,56 與 36,54、腳踝 15,105 與 27,103、刀 122° 從腿間往後下方穿過；小腿長改為 21），所以**待機就是站姿圖用自己的零件組回來**（帶呼吸），每個招式都從這個姿勢起手、回到這個姿勢，不再有圖片與零件之間的跳動。刀有三層：back（兩腿後）、mid（後腿前、義足後——站姿圖的層次）、front；後腿先畫、義足在上。肢體不拉伸；相鄰兩格之間 60fps 補間；影子、殘影、倒影同一組零件。按 B 切回逐格繪製，`?puppet=0` 一開始就關。
- **前後側面素材表**（ref/jk_parts_c.jpg，4.44px 格）：三個視角的比例不一致（側視約 0.8 倍、正視約 1.2 倍世界尺度），所以只取了側視圖裡畫好的膚色手臂（前臂、手，`ref/parts_jk3.py`，res 1.4）取代原本程式畫的圓柱手臂；背面／側面整套零件若要做轉身格，需要與分件圖同比例的版本。
- **刀被打飛**：刀這個部位被打斷時不再只是變短——整把刀從手上旋轉飛出、落地插在地上（`sim.props`），JK 空手繼續打（刀招變成空揮、傷害 ×0.85）；走到刀旁按 ↓ 撿回，耐久回一半。CPU 也會去撿。倒地動作的高度已修正（旋轉軸在腰上 16px，落地格的 lift 對應調整），身體貼地不再浮空。頁面只剩遊戲畫面（標題與說明面板拿掉）。
- **最新動作表的招式名與特效**（ref/jk_actions4.jpg）：必殺技照表命名——C 影分身・居合、↓C 電磁衝撃破（光彈改用表上那顆青紫大能量球，Scale2x）、新增超必殺 V 量子爆裂（三段彩虹環蓄力，程式畫的多色電弧＋圓環；爆炸用表上的爆裂格 Scale3x），氣槽滿才能放；`src/frames-jk4.js` 只收這兩個特效格，`src/sheetfx.js` 支援整格（whole）與 ×2／×3 放大。
- **動作參考補齊**（三張動作表）：Z 連段插入義足ミドルキック（青色殘影）、義手ジャブ帶火花、↓Z 連按炎の足払い（義足拖火掃腿、擊倒）、空中↓Z 空中義足（急降下踢）、閒置約 3.6 秒且對手不在近處時播「構え直し」（把刀扛上肩、甩髮、回到構え）、勝利改為舉拳→盤坐把刀橫放腿上呼吸循環。零件切法：`ref/parts_jk6.py`（站姿圖原像素，袖子鏡射、刀以站姿圖的刀身／刀柄顏色重繪）→ `ref/parts_x2.py`（全部 Scale2x 為 res 2）。

## 做法

畫面 480×270、角色約 96～110px（KOF 尺寸）：頭、手、腳是手打點陣；上身用「材質圖」由骨架自動上明暗與接縫；四肢是圓柱明暗的筆畫；長髮是帶髮縷的飄帶。


全部點陣都是程式畫的（沒有圖片檔）：

- `src/px.js` — 1x 光柵器：材質色階、部件分離邊、外框、翻轉／旋轉。
- `src/rig.js` — 共用骨架：手繪點陣部件（頭、上身、裙、鞋）＋ IK 擺放的四肢筆畫、上身傾斜、長髮飄帶、受擊框。
- `src/jk.js` `src/vamp.js` `src/maid.js` — 三位角色（女僕含狼化型態）的點陣與破損變化。
- `src/anims.js` — 所有動作逐格定義：預備→殘影→命中→追隨→收回，含判定框與傷害。
- `src/fx.js` — 揮擊殘影、命中火花、塵土、電光等效果。
- `src/stage.js` — 480×180 的夜晚校門舞台（視差捲動）。
- `src/game.js` — 60Hz 固定步進：輸入、物理、判定、部位傷害、投射物、CPU、回合流程與 HUD。

檢視工具：`node tools/sheet.js out.png 8 jk poses.js`（姿勢表）、`node tools/anim.js out.png jk light heavy 5`（動作分格，紅框＝判定框）、`node tools/build.js`（打包成 `dist/index.html`）。
