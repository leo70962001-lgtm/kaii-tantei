# 點陣圖做法（蒸餾版）— 從 AI 動作表到遊戲精靈

這份是在「怪異探偵部 PART BREAK」上反覆試出來、最後真正有效的方法。原則只有六條：

1. **來源圖為真**：遊戲裡的每一個像素都直接來自動作表的像素，不重新上色、不加外框、不合成五官。
2. **先量化再動手**：任何「精緻化」都先用逐格、逐部位的數字比較（色差／顏色數／邊緣能量／漏像素）證明有進步。
3. **1:1**：精靈的像素密度要等於畫布能顯示的密度（960×540 畫布 ⇒ 164px 高的格子以 0.5 世界倍率繪製）。
4. **定點要穩**：錨點取上身核心，不取雙腿中心；動作之間身體不跳。
5. **不留痕跡**：格號、分隔線、取樣空洞、黏連的鄰格都要處理掉。
6. **動作照拍點**：起手 → 殘影格 → 命中（hold）→ 追隨／回收；關鍵姿勢先定。

---

## 1. 分析來源圖

- `ref/grid_analysis.py <圖>`：梯度自相關找「像素格」週期。AI 畫的動作表週期峰值在 1px ＝ **沒有真像素格**（只是像素風的畫），所以不能用 4px 區塊平均；真正的點陣圖（例如 OMAR. 的制服少女）會有乾淨的 3px 格。
- `ref/analyze_b.py`：在原圖解析度逐格量：人物框、高度、腳底線、相對待機格的比例（步行格常小 8%）、眼睛位置（膚色框上半的深色團）、每種材質的實測顏色（亮度百分位）、輪廓顏色與粗細。結果 `ref/art/analysis_b.json` 給後面的取樣用。
- 同版面的多張重繪版（原稿 → 編號向量版 → 無編號細緻版）先量全圖位移（暗像素重疊最大化），位移 0 就能共用切格幾何。

## 2. 切格

- `ref/cells.py <表>`：4px 格取樣、塗掉標題色帶與方框（只沿黑色像素從色帶走進去，別吃掉人物輪廓）、連通塊切格、被刀身／殘影連在一起的鄰格用「有高瘦主體的欄」切開、特效依顏色分層（青／洋紅／橘黃／**血**種子）、錨點、每張表以多數決判朝向。
- 編號版先用 `ref/clean_v.py` 塗掉格號（小的白色連通塊、四周幾乎全是背景）。
- 特效相連而黏成一格的（雷電踢／炎踢、吹き飛び／倒れ）用 `ref/split_v.py` 在原圖 x 切開並各自重算錨點；切格器把左人物另外吐出時，把它放回合併格左半的畫布並接上該半的特效。

## 3. 取樣（`ref/refine2.py raw`）

- 每個精靈像素＝一個原圖像素（UP 4 → 164px 格）。視窗為空（縮放過的格子）時取最近的原圖像素，否則整格會被打出透明格線。
- 剪影：切格遮罩膨脹一圈內、非背景色的像素；特效從特效遮罩重切。
- 尺寸漂移校正：直立格（寬高比 < 0.62、高度 ≥ 待機高 80%）縮放到待機高度，其他格取同列直立格的中位倍率。
- 分隔線：格緣 5 欄內、左右鄰欄幾乎全空的深色高欄（含虛線），由內往外掃兩遍後移除。
- 來源缺格：`FALLBACK` 自動退回另一版同版面的表。`tag:V` 只重跑一張表。
- 錨點：上身核心欄的中心（人物高度 28–55% 的列裡像素數 ≥ 最大值 60% 的欄），y ＝ 最低像素。
- 邊緣：動作表的輪廓外圍有 1–2px 與背景混色的過渡像素，原樣搬進遊戲會帶著背景色的「泥邊」。`unblend()` 依「離背景色的距離」給 4 階透明度（63／127／191／255）並把顏色從背景色解混回來，邊緣在任何場景上都乾淨。
- 編碼：`prla`（RGBA 調色盤 ≤ 255 色＋RLE，每個透明階各自量化），`src/sprite.js decode()` 同步解碼；4.3MB 內裝 177 格 164px。
- 網路上蒐集的「更精細」做法只當可量測的選項（用逐部位數字決定要不要）：PixelRefiner／Tidy Pixel Art（找回真實像素格再重取樣）、Pixel-Extractor／Pixel Snapper（偵測格距、最近鄰對齊）、Retro Diffusion 式的清理（Oklab 空間 k-means 量化、去斑、限制調色盤）。對沒有真像素格的 AI 畫，格距偵測無效；量化與去斑會把顏色數壓回去、色差上升；1:1 取樣後真正有效的只有邊緣解混。

## 4. 引擎

- `src/sprite.js`：SCALE < 1 的表保留格子原尺寸的畫布，`frame()` 回傳世界 px 的 w/h/ox/oy/figBox 與 `ds`（繪製倍率）、`pw/ph`（像素尺寸）。
- `src/game.js` / `src/gl.js`：img 項帶 `w/h`；影子與刀道具矩陣乘 ds；光彈用 `worldW/H`；rect 項支援透明度。
- 判定框以世界 px 手寫（K＝1），不隨格子解析度變。

## 5. 動作表

- 每招：起手（可讀的預備，40–100ms）→ 殘影格（50ms，一格弧形）→ 命中格 hold（60–110ms）→ 追隨／回收（70–120ms）；命中時 shake／hitstop。
- 關鍵姿勢先定（預備、擊中、追隨），三格看得懂才算清楚。
- 受擊 3 格、吹き飛び 3 格＋著地 2 格＋躺、步行 4 格、待機 2 格呼吸＋構え直し 5 格。
- 判定框由格內拳／腳／刀的像素位置決定，`tools/strip.js` 畫出來核對。

## 6. 逐部位比較（迭代的尺）

- `ref/compare_parts.py V A C`：每格分頭／上身／腰裙／腿，量「與動作表的平均色差（0–255）、顏色數、邊緣能量比、漏像素」，輸出 `ref/art/compare/<格>.png`（動作表｜舊｜新｜誤差圖）與 `report.md`。
- 目前基準（邊緣解混後，129 格）：色差 5.7–7.9、顏色 181–230、邊緣 1.20–1.34、漏像素 3.5–6.1%（邊緣比原畫銳是解混掉泥邊的結果，不算退步；解混前為 5.6–7.8／173–226／0.93–0.94／3.7–6.3%）。任何新做法要贏過這組數字才採用。

## 7. 舞台

- 舞台以原畫密度繪製（720×270，1 世界 px），不要為了配合粗糙精靈再減半。
- 會動的背景寫成時間的純函數 `STAGE.anim(t)`（花瓣、燈光閃爍、窗戶、雲、星、蝙蝠、貓），遠景項手動乘視差 0.35，背景項在人物前繪製、`front` 項最後。
- 可破壞物（`STAGE.PROPS`）：自動販賣機、腳踏車、校門兩盞燈、立て看板、垃圾桶、三角錐×2。每個道具三個狀態（完好→受損→破壞）各自用舞台同一套像素畫法畫成一張圖（抖色、亮邊暗邊、1px 輪廓；倒下的姿勢用整張 90° 旋轉再加散落物），`propImage(kind, state)` 只畫一次；`hit` 是攻擊判定用的完好剪影、`box` 是圖的範圍（放得下倒下的姿勢）。`game.js tickBreakables()`：攻擊判定框／被打飛的身體（2 點）／光彈碰到就扣血，同一次出招只算一次（鍵放在 `f.hitIds`，出招時重設），破壞時碎片粒子＋震動＋音效；燈與販賣機破壞後 `anim()` 不再畫光暈。
- 近景層**不要**畫道具會取代的東西（牆上的燈與光斑改由燈道具畫）：GL 的泛光是從近景層的亮像素另外算的，蓋在上面的暗圖擋不住它，燈打壞了還會發光。道具自己的亮像素（燈玻璃、販賣機的窗）用 `fx`（亮度 ≥ 200 的像素）交給泛光層。

## 8. 驗證

- `node scratchpad/check_sprites.js`（所有招式格解碼）、`node tools/strip.js out.png <招式…> 2`。
- 瀏覽器面板隱藏時 rAF 停、截圖不更新：用 `__game.startMatch` ＋ 設定 `f.input` 手動 `__game.step()` 驗證命中；抓畫面用 `?gl=0` → `__game.renderOnce()` → `cv.toDataURL('image/jpeg')`（結果存成檔案再解碼）。
- 手動測試打道具：引擎每步會把沒在出招的人轉向對手、並把人夾在鏡頭窗內，所以先把 `sim.camX = sim.camTarget` 設到位、把對手放在道具那一側，再 `__game.play(f, '招式')`。
- GL 畫面抓圖：`document.getElementById('gl').toDataURL()` 要在遊戲的 rAF 之後讀（連續兩層 `requestAnimationFrame`），而且面板要在前景才會更新。

## 9. 行不通的（別再試）

- 每材質壓成 3 階色＋人工外框＋合成眼睛：臉、髮絲、義足板片全變色塊（色差 39–56）。
- 半解析度（82px 格再 ×2）：畫布一半解析度白白浪費。
- 親和力分區決定材質：小臉被膚色區域淹掉。
- 雙腿中心當錨點：踢腿、前衝時整個人左右跳。
- 手繪 ASCII 部件重組人物：比 AI 動作表本身的畫差，使用者要求回到表格。
- 把亮的東西畫在近景層再用道具圖蓋掉：GL 泛光穿透，打壞的燈還在發光（見 7）。
- 道具命中鍵用招式的固定編號：同一招整場只能打中一次；要用每次出招重設的 `f.hitIds`。
- 對 1:1 取樣後的格子再做量化／去斑：顏色數掉回去、色差上升。

## 指令速查

```bash
py -3 ref/grid_analysis.py ref/<表>.jpg
py -3 ref/clean_v.py                  # 去格號（編號版）
py -3 ref/cells.py V && py -3 ref/split_v.py
py -3 ref/analyze_b.py
py -3 ref/refine2.py raw              # 全部；raw tag:V 只重跑 V
py -3 ref/compare_parts.py V A C
node tools/strip.js out.png idle walk light heavy 2
node tools/publish.js "訊息"
```
